# 本の整理

## 中心命題

『悪文』が問うていることは一つである。想定読者は、その文章を無理なく、誤解なく受け取れるか。主眼は誤り探しではなく、文章が伝達としてどこで失敗するかを見つけることにある。

全体を通じて特に強い原則は次の二つである。

- 書き手の頭の流れではなく、読み手の読み進め方に合わせて書く。
- 語句の磨き込みより先に、構造を直す。

## 持ち運びやすい枠組み

本書の助言は、次の六層に整理できる。

1. 目的と読者
2. 段落と配列
3. 文の切り方とつなぎ方
4. 論理、省略、助詞、並列
5. 修飾関係と句読点
6. 語の選び方、敬語、文体の統一

## 章ごとの要点

### 1. `悪文のいろいろ`

冒頭では、悪文を「わかりにくい」「誤解される」「堅すぎる」「混乱している」文章として捉える。ここで効いてくる教訓は、一読で通ることの重さである。

### 2. `構想と段落`

段落は見た目の飾りではない。思考をどこで区切り、どう配列したかを示す構造である。各段落が何をしているかを決めていない文章は、たいてい読み手にも伝わりにくい。

この skill への持ち込み方:

- 各段落の役割を言い表せるかを確かめる。
- 役割が曖昧なら、文を直す前に段落設計をやり直す。

### 3. `文の切りつなぎ`

長すぎる文、結論が遅すぎる文、接続関係が見えにくい文を警戒する章である。調子や歯切れも扱うが、まず線の通った接続が前提になる。

この skill への持ち込み方:

- 一文で抱え込みすぎている要素を分ける。
- 読者が先に見取り図を必要とするなら、結論や枠を早めに示す。
- 漠然とした接続に頼らず、必要なら関係を言い分ける。

### 4. `文の途中での切り方`

中止法、長い連鎖、弱い句読点は、流れているように見えて実は読者の負担を増やすことがある。特に、どこにどうつながるのかを読者が推理しなければならない文を問題にする。

この skill への持ち込み方:

- `て` `が` などが関係をぼかしていないかを見る。
- 句読点で読み筋を見せる。
- 読み上げ原稿なら、一度聞いて取れるかを重視する。

### 5. `文の筋を通す`

主述の崩れ、危険な省略、並列の不整合、副詞の収まりの悪さ、助詞の置き方のまずさなど、文内部の論理の乱れを扱う。

この skill への持ち込み方:

- 主語と述語の対応を見える形に保つ。
- 省略で危なくなる主語や目的語は戻す。
- 並列は意味と形の両方で並列にする。

### 6. `修飾の仕方`

助詞の重複や脱落、修飾のかかり先の曖昧さ、長い修飾語、挿入句による流れの中断が中心である。

この skill への持ち込み方:

- 修飾語を被修飾語の近くへ寄せる。
- 長い連体修飾は別文にほどく。
- 曖昧さを避けるためなら、被修飾語を繰り返す。

### 7. `言葉を選ぶ`

独りよがりな新語、重複表現、不自然な連語、ちぐはぐなイメージ、堅すぎる語、気分に流された語の選び方を問題にする。

この skill への持ち込み方:

- 普通で正確な語を優先する。
- 空疎に大げさな言い回しを引き下げる。
- 比喩やイメージの場が途中でぶれていないかを見る。

### 8. `敬語の使い方`

平明で簡素な敬語を勧め、`お/ご` のつけすぎを戒め、尊敬語と謙譲語の違いを押さえ、文体の統一を求める。

この skill への持ち込み方:

- 敬語は飾りではなく適合のために使う。
- 丁寧さの印を重ねすぎない。
- 目的がない限り、文体を一貫させる。

### 9. `悪文を避けるための五十か条`

終章の確認表は、本書を実務的なチェックリストに圧縮した部分であり、agent skill にとって最も再利用しやすい。

## 現代にも残るものと、注意して扱うもの

### いまも強い原則

- 読者本位の明晰さ
- 段落構成を思考構造として捉える視点
- 短くはっきりした文の接続
- 省略、修飾、句読点への慎重さ
- 平明な語を選ぶ姿勢
- 節度ある敬語と文体の統一
- 音声で聞かれる文への配慮

### そのまま固定化しないほうがよい点

- 例文の評価には、戦後中期の新聞文体、広告文体、役所文体への反応が混じる。
- 皇室敬語など、一部の敬語判断は時代性が強い。
- 当時は不自然とされた言い方の一部は、現代では定着している可能性がある。

したがって、現代化のしかたは「禁止事項を丸写しする」ことではなく、「原理を残し、局所判断を更新する」ことである。

## この skill での使い方

- 本を資料集ではなく、診断法として扱う。
- 「書き手の整理不足を読者に肩代わりさせない」という核を守る。
- 何でも文法用語で片づけず、読者がどこで迷うかで説明する。
- 語の磨き込みの前に、意味と構造を直す。
